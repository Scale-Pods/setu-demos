# Matdaan Mitra — redesigned front-end

Dark-first glassmorphism redesign of the Matdaan Mitra voter-assistance concept demo. Front-end only; all data is mocked.

```bash
npm install
npm run dev
```

Routes: `/` (voter slip scan), `#citizen`, `#officer`, `#platform`. Staff sign-in: lock icon → role picker. "Play guided demo" runs an 11-step tour.
Four states (UP, UK, Punjab, Maharashtra) with their own accent, languages and data.
